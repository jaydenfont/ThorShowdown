title ThorShowdown Battle Flow (A1: native client + view-only WebView)

participant BottomScreen
participant GameViewModel
participant Repository
participant Matchmaker
participant SessionManager
participant ShowdownClient
participant "Showdown Server" as Server
participant "TopScreen (WebView)" as WebView

note over ShowdownClient,Server: App start: open WebSocket and log in
ShowdownClient->Server: connect WebSocket
Server-->ShowdownClient: |challstr|
ShowdownClient->Server: POST /api/login (name, pass, challstr)
Server-->ShowdownClient: assertion
ShowdownClient->Server: |/trn username,0,assertion
Server-->ShowdownClient: |updateuser|username|1|...
ShowdownClient-->Repository: LoginResult.Success(username, sid)
Repository->WebView: WebSession.signIn(sid): sid cookie via CookieManager
note over Repository: then loginState = LoggedIn

BottomScreen->GameViewModel: onAction(FindBattle(Gen9RandomBattle))
GameViewModel->Repository: startSearch(format) (only when logged in)
Repository->Matchmaker: start(format): Requested, 10 s timeout
Matchmaker->ShowdownClient: useTeam(null), search(format)
ShowdownClient->Server: |/utm null, |/search format
Server-->ShowdownClient: |updatesearch| searching = [format]
Repository->Matchmaker: handle(UpdateSearch): Searching
note over Server: matchmaking (async, can take minutes)
Server-->ShowdownClient: |init|battle (roomId)
ShowdownClient-->Repository: messages flow
Repository->SessionManager: handle(RoomInit): new session, now current
Server-->ShowdownClient: |updatesearch| searching = []
Repository->Matchmaker: handle(UpdateSearch): Idle
SessionManager-->GameViewModel: currentRoomId
GameViewModel-->WebView: show room (roomId)
WebView->Server: own connection: open battle room (view only)
note over WebView: inject battle.js + battle.css: hide controls, scale battle

loop each turn
Server-->ShowdownClient: |request| {active, moves, switches}
ShowdownClient-->Repository: messages flow
Repository->SessionManager: handle(Request)
SessionManager-->GameViewModel: battleState
GameViewModel-->BottomScreen: bottomState (available moves)
BottomScreen->GameViewModel: onAction(ChooseMove(1))
GameViewModel->Repository: chooseMove(roomId, 1)
Repository->SessionManager: chooseMove(roomId, 1)
SessionManager->ShowdownClient: send("roomId|/choose move 1|rqid")
ShowdownClient->Server: roomId|/choose move 1|rqid
note over Server: waits for opponent, then runs the turn
Server-->ShowdownClient: turn events (|move|, |-damage|, |turn|)
ShowdownClient-->Repository: messages flow
Repository->SessionManager: handle(events)
Server-->WebView: same turn events (animates)
end

Server-->ShowdownClient: |win| username
ShowdownClient-->Repository: messages flow
Repository->SessionManager: handle(Win): result set, session kept
SessionManager-->GameViewModel: battleState (result)
BottomScreen->GameViewModel: onAction(LeaveRoom)
GameViewModel->Repository: leave(roomId)
Repository->SessionManager: leave(roomId)
SessionManager->ShowdownClient: send("roomId|/leave") (forfeits first if unfinished)
Server-->ShowdownClient: |deinit|
ShowdownClient-->Repository: messages flow
Repository->SessionManager: handle(RoomDeinit): session removed
SessionManager-->GameViewModel: currentRoomId = next session or null
GameViewModel-->WebView: show that room, or the idle view
